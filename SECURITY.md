# Security and privacy baseline

- This platform is informational and is not an official reporting authority.
- Never request intimate media, passwords, recovery codes, or unnecessary identity data.
- Encrypt consultation contact details and descriptions before storage; never include them in URLs, logs, analytics, or ordinary email bodies.
- Country authorities, laws, numbers, and URLs remain unpublished until a legal reviewer records verification and a date.
- Privileged users require MFA in production. Only support roles may view consultation cases.
- Production requires HTTPS, encrypted secure cookies, Redis throttling, external secrets, restricted database credentials, encrypted backups, and tested restoration.
- Run dependency audit, automated authorization tests, OWASP ASVS review, accessibility audit, and professional penetration testing before launch.
